## 🎯 Objetivo Principal

El objetivo fundamental de la materia **Seminario de Integración** es consolidar y unificar los conocimientos avanzados en el desarrollo de software **Full-Stack**, integrando arquitecturas modernas de backend de alto rendimiento con interfaces de usuario robustas y escalables en el frontend, aplicando buenas prácticas de ingeniería de software, tipado estático y gestión eficiente de dependencias.

## 🚀 Tecnologías Utilizadas

A continuación se describen brevemente las tecnologías y herramientas principales que componen el stack tecnológico de la materia:

### 🐍 Python

Lenguaje de programación interpretado, de alto nivel y multiparadigma. Es ampliamente valorado por su sintaxis limpia y su versatilidad, sirviendo como la base para el desarrollo del backend y la lógica de negocio de la aplicación.

### ⚡ uv

Gestor de paquetes y dependencias ultrarrápido para Python desarrollado en Rust por Astral. Está diseñado para reemplazar de manera eficiente herramientas tradicionales (`pip`, `virtualenv`, `poetry`), acelerando la creación de entornos virtuales y la resolución de paquetes de forma drástica.

### 🚀 FastAPI

Framework web moderno, de alto rendimiento y asíncrono para construir APIs con Python. Destaca por su velocidad comparable a NodeJS/Go, su validación automática de datos basada en *Pydantic* y la generación automática e interactiva de documentación (Swagger UI y ReDoc).

### 🔷 TypeScript

Superconjunto tipado de JavaScript que añade tipado estático opcional y características avanzadas de orientación a objetos. Permite detectar errores en tiempo de desarrollo y mejora la mantenibilidad del código en proyectos complejos.

### 🅰️ Angular

Framework robusto y basado en componentes desarrollado por Google para la construcción de aplicaciones web de una sola página (SPA) y escalables. Utiliza TypeScript de forma nativa e incluye un ecosistema completo para el manejo de formularios, enrutamiento y peticiones HTTP.
